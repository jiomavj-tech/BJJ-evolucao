CALISTENIA + BJJ — PRIMEIRA VERSÃO (0.1)

1. Este ZIP contém o código completo e editável da PWA. Ainda não está publicado na Internet.
2. Para testar no computador: extraia a pasta e, com Python instalado, execute nela:
      python -m http.server 8080
   Depois abra http://localhost:8080 no navegador.
3. Para instalar no celular: publique os arquivos em uma hospedagem HTTPS (ex.: GitHub Pages).
   No Chrome Android, abra o endereço e selecione o menu ⋮ > Instalar app.
4. Para salvar seu histórico: Ajustes > Baixar backup JSON. Para trocar de aparelho,
   use Restaurar backup. O histórico NÃO sincroniza sozinho.
5. Se estiver sem energia ou indisposto, ajuste a prontidão para 1/5 ou 2/5;
   o app substituirá a sugestão de força por uma sessão de recuperação opcional.

Se quiser apenas visualizar a interface sem instalar nada, use também o arquivo
calistenia-bjj-demo.html entregue separadamente. Ele não é uma PWA instalável.

mais completo ainda não foi realizada e depende da revisão de segurança.
